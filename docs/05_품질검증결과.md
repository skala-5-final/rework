## 5. 재현 방법

```bash
docker compose up -d --build --scale worker=3
cd scripts/quality

uv run python runs.py 30 3                 # Q-10 + 표준 분석 30회 (var/quality/runs.json)
uv run python run_metrics.py               # Q-04, H-01, H-02, H-03(표준), H-05
uv run python rerun.py                     # Q-05
uv run python duplicates.py                # Q-08
./run_in_container.sh mcp_checks.py <완료된 job_id>   # Q-11(MCP), Q-14, Q-17
docker compose stop worker
uv run python api_perf.py                  # Q-09
uv run python access_api.py                # Q-11(API)
docker compose up -d --scale worker=3
uv run python privacy_check.py             # Q-12
caffeinate -i uv run python faults.py      # Q-06, Q-07 (약 30분)
uv run python run_metrics.py ../../var/quality/fault_runs.json H-01,H-02
caffeinate -i uv run python guards.py      # H-03, H-04 (한도를 낮춘 Worker로 시나리오)
caffeinate -i uv run python deploy_check.py  # Q-16 (기존 스택을 잠시 멈춤)
cd ../.. && uv run pytest --cov=src/rework --cov-branch --cov-report=json:var/quality/coverage.json
uv run python scripts/quality/coverage_check.py   # Q-13
```

결과는 `var/quality/<ID>.json`에 쌓이고, 이 문서가 인용한 버전은 `docs/quality/`에 있다. 장시간 측정은 실행 중 절전으로 멈추지 않도록 `caffeinate`로 감싼다.
